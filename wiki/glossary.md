# Glossary

| Term | Definition |
|---|---|
| **Trekie** | The product — a gamified life dashboard |
| **Momentum** | A quantified score measuring a user's productivity and consistency |
| **Factor** | A component that influences momentum (consistency, focus, habits, tasks) |
| **Delta** | The change in momentum between two time periods |
| **Commitment** | A specific repeatable action tied to a goal |
| **Goal** | A high-level objective the user wants to achieve |
| **ABAC** | Attribute-Based Access Control — fine-grained permissions |
| **Better Auth** | Authentication library handling sessions, passwords, OAuth |
| **ElysiaJS** | Bun-native HTTP framework used for the API |
| **tRPC** | End-to-end typesafe RPC between frontend and backend |
| **Drizzle** | TypeScript ORM for PostgreSQL |
| **Dexie** | IndexedDB wrapper for local-first data storage |
| **Zustand** | Lightweight state management for React |
| **Shadcn UI** | Copy-paste component library built on Radix UI primitives |
| **SpecKit** | The `.specify/` workflow for spec-driven development |
| **Dorkodu** | The company behind Trekie (dorkodu.com) |
| **ULID** | Universally Unique Lexicographically Sortable Identifier |
| **Neverthrow** | Functional error handling library using Result/Option types |
| **LangChain** | AI/LLM framework used for momentum explainer and recommendations |
| **LangGraph** | State machine framework for AI agent workflows |
